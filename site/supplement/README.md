# Early Earth — proposed supplementary figures

This selection brings together energy changes, alanine geometry and fragment populations before and after quenching. It is a proposed supplement; the final manuscript figure selection remains under review.

Start with **[the gallery](index.html)**. Filter by theme, or search a title,
figure ID or filename. Click a preview for full resolution; PNG/PDF variants
share a card. [The reading guide](START_HERE.html) explains the collection.
Continue to the [complete figure library](../index.html) for the other collection.

Figure descriptions explain what is shown. Expand **Figure details** for the
technical notes, source paths and hashes. Simulation views and representation
diagnostics appear in the full library; they are not all manuscript candidates.
Distinct strings describe observed connectivity, rather than independently
confirmed chemical species. Repeated appearances describe sampling recurrence,
rather than fragment lifetimes.

Choose **Comments** beneath a figure, sign in with GitHub, and leave feedback
or reply in the gallery. Comments are public and attached to the reviewed artwork
version. PNG/PDF variants and matching supplement cards share a discussion.

[catalog.csv](catalog.csv) and [export_manifest.json](export_manifest.json)
record figure provenance. This website contains portable figure copies and
their reading-view dependencies. Source figures are unchanged. Some HTML
views load external MathJax/RequireJS libraries and need internet access.

The maintained gallery sources are in
[nterrel/early-earth-figures](https://github.com/nterrel/early-earth-figures).

Shared review uses public GitHub Discussions. Nick and Adrian curate the discussion set; signed-in GitHub users can add notes and ratings. Prepare a selection/rating/note in the gallery, copy it into Comments, and post. The shared view updates after GitHub Pages republishes. Refresh to load the latest snapshot. This does not approve manuscript panels.
